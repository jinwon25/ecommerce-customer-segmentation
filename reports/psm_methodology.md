# 쿠폰 사용 관찰연구 — PSM 기반 매칭 분석

이 분석은 쿠폰 사용 고객과 클릭만 한 고객의 60일 결과를 비교한다. 72쌍 매칭 후에도 16개 공변량 중 6개가 `|SMD| ≥ 0.1`이고, 전체 사용 고객 1,208명 중 72명만 포함된다. 따라서 결과는 전체 처치군 ATT가 아니라 **분석된 매칭 표본의 관찰 차이**이며 A/B 테스트 가설로 사용한다.

## 분석 개요

**처치 / 대조 정의**
- 처치군: `쿠폰상태 = 'Used'` 거래 ≥ 1건 (n = 1,208). 첫 Used 거래일이 처치 시점.
- 대조군: `Used` = 0 & `Clicked` ≥ 1건 (n = 72). 첫 Clicked 거래일이 처치 시점 (대칭 정의로 selection 통제).
- 모집단 cap: 처치 시점 ≤ 2019-10-31 (60일 outcome 보장).

**공변량 9개 → 최종 16개 변수**
가입기간, 성별, 고객지역(one-hot), 첫거래월(one-hot), 기준일 이전 거래 없음, pre-Frequency, 사전 평균 상품행 금액, pre-카테고리다양성, pre-거래일수 ≥ 2.

pre-Frequency·사전 평균 상품행 금액·pre-카테고리다양성의 0 여부가 신규 고객 지표와 100% 일치해 PS 모델에서 중복 변수를 제거했다. pre-거래일수 ≥ 2는 대조군 내 분산이 0이라 제외했다. 데이터의 95.2%가 기준일 이전 거래가 없는 고객이어서 최종 모델은 고객 속성·첫 거래월과 신규 고객 지표에 주로 의존한다.

**매칭**: 1:1 nearest neighbor, distance = logit(PS), caliper = 0.2 × SD(logit PS) = 0.0845, without replacement, greedy. 대조군과 후보 처치군을 고객ID로 정렬하고, 거리가 같으면 고객ID가 작은 후보를 선택해 실행 순서를 고정한다. 결과는 72/72(100%) 매칭이며 매칭 거리 최댓값은 0.0198이다.

## 본 데이터의 두 가지 큰 특성

본 분석의 모든 해석은 다음 두 특성 위에 선다.

1. **처치 / 대조 비대칭 94.4 : 5.6** — 대조군을 기준으로 처치군을 찾는 1:1 매칭이라 72쌍만 남는다. 이는 전체 처치군 ATT가 아니라 선택된 72명 처치군과 72명 대조군의 매칭 표본 차이다.
2. **기준일 이전 거래가 없는 고객 95.2%** — 사전 구매 행동으로 사용군 선택을 충분히 설명하기 어렵고 PS 모델이 고객 속성·첫 거래월에 크게 의존한다.

## PSM 가정 3가지 검토

| 가정 | 본 데이터에서의 상태 | 검토 |
|---|---|---|
| **SUTVA** | 검증 불가 | 개인 간 spillover 정보와 캠페인 운영 로그가 없어 데이터만으로 충족을 확인할 수 없다. |
| **Ignorability** | 충족 근거 부족 | 관측 9개 공변량만 사용했고 캠페인 관심도·시점별 마케팅 강도·구매 의도 같은 미관측 교란 가능성이 남는다. 낮은 pseudo R²는 교란이 약하다는 증거가 아니다. |
| **Common Support** | 범위 겹침 확인 | PS 범위는 처치 96.6%·대조 100%가 겹치지만, 이는 매칭 후 공변량 균형을 보장하지 않는다. 실제로 6/16 변수가 `|SMD| ≥ 0.1`이다. |

세 가정 모두 인과효과를 확정할 수준으로 검증되지 않았다. 특히 ignorability와 매칭 후 균형이 핵심 제약이다.

## 핵심 결과

### 1. 양의 관찰 차이는 남지만 인과 결론은 보류

| outcome | 단순 차이 (1208 vs 72) | 72쌍 매칭 차이 |
|---|---|---|
| 60일 리텐션 (binary) | +25.55%p (CI 20.14, 30.24) | **+34.72%p** (CI 22.22, 45.83) |
| 60일 상품매출 (수량 × 단가) | +$487.46 (CI 403.33, 601.84) | **+$964.75** (CI 346.75, 2,047.27) |

매칭 차이가 단순 차이보다 점추정상 크다. 그러나 매칭된 처치군이 전체 1,208명 중 72명이고 공변량 균형도 충족하지 않아, CI가 0을 포함하지 않는다는 사실만으로 인과효과나 강건성을 주장할 수 없다.

### 2. 균형 진단이 결론의 범위를 제한한다

매칭 후에도 `region_Chicago`, `region_New Jersey`, `first_purchase_month_3·5·6·10`의 6개 변수가 `|SMD| ≥ 0.1`이다. 성과 차이의 CI가 0을 포함하지 않더라도 관측 공변량의 교환가능성이 확보되지 않았으므로 인과효과로 승격하지 않는다.

낮은 propensity model 설명력 역시 selection bias가 작다는 증거가 아니다. 모델이 사용 선택 메커니즘을 충분히 설명하지 못했거나 중요한 공변량이 누락됐을 가능성이 남는다.

### 3. 분석 한계 — 표본 · 비대칭 · 신규 고객 편중

- 매칭 페어가 72쌍뿐이라 bootstrap CI가 넓다
- 처치 94 : 대조 6의 비대칭 — 대조군 기준 72쌍만 남아 모집단 estimand가 불명확함
- 기준일 이전 거래가 없는 고객 96% 편중 — 매칭된 각 군에서 이전 거래가 있는 고객은 3명뿐이라 별도 해석을 보류
- 16개 중 6개 공변량이 매칭 후에도 `|SMD| ≥ 0.1`

한계 명시 자체가 분석 결과의 일부.

## 재현 방법

`sql/05_coupon_observational_population.sql`은 BigQuery용이고, 다음 로컬 경로가 동일 정의를 pandas로 구현한다.

```bash
python scripts/build_coupon_population.py \
  --sales data/Onlinesales_info.csv \
  --customers data/Customer_info.xlsx \
  --output data/coupon_population_private.csv

python scripts/run_coupon_matching.py \
  --input data/coupon_population_private.csv \
  --effects-output data/derived/matched_effects.csv \
  --balance-output data/derived/matched_balance.csv
```

고객 단위 중간 파일은 식별자를 포함하므로 커밋하지 않는다. 공개 저장소에는 결과와 균형 진단의 비식별 집계만 둔다. 다음 의사결정은 이 관찰 점추정의 추가 세분화가 아니라 [무작위 A/B 테스트 설계](ab_test_design.md)로 검증한다.
