# 관측 고객가치 지표 정의

이 프로젝트는 12개월 데이터만 있어 고객의 미래 생애가치를 안정적으로 추정하기 어렵다. 따라서 `LTV`라는 이름 대신 2019년 관측기간에서 직접 계산 가능한 지표를 분리해 보고한다.

| 지표 | 정의 | 용도 |
|---|---|---|
| 관측누적매출 | 고객의 2019년 거래금액 합 | 기간 내 매출 기여 규모 |
| 활성월수 | 구매가 한 번 이상 발생한 고유 월 수 | 구매활동의 시간 분산 |
| 구매일수 | 구매가 한 번 이상 발생한 고유 날짜 수 | 거래ID 중복에 덜 민감한 활동 빈도 |
| 활성월당매출 | 관측누적매출 / 활성월수 | 활동 월의 평균 매출 강도 |
| 구매일당매출 | 관측누적매출 / 구매일수 | 구매일의 평균 매출 강도 |
| 구매일간격 | 서로 다른 구매일 사이의 일수 | CRM timing의 탐색 기준 |

`sql/04_customer_value.sql`은 고객 단위 테이블과 세그먼트 요약 테이블을 만든다. 어느 지표도 미래 매출 예측치가 아니며, 세그먼트 비교에는 평균과 중앙값을 함께 사용한다.

미래 LTV가 필요한 경우에는 더 긴 관측기간, holdout 기간, 거래 빈도와 금액의 독립성 점검을 먼저 확보한 뒤 BG/NBD·Gamma-Gamma 또는 코호트 잔존가치 모델을 평가한다.
